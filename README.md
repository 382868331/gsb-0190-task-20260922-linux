# mtiso — 体素等值面的共享边交点提取

离线、纯标准库的 marching tetrahedra（MT）等值面提取题库。每个立方体按
**统一主对角线**剖成 6 个四面体，所有等值面交点按**全局网格边键**共享
（同一条网格边只插值一次），输出朝标量增大方向的三角形网格及组合/几何
统计。

## 运行环境

- Python **3.14.7**（语法仅用 3.10+ 特性亦可，但按 3.14.7 验证）
- **无第三方依赖**，仅标准库（`math`、`dataclasses`、`typing`）。
- Linux 原生；不需要网络、账号、密钥、数据库、中间件、云 API 或 Docker。

## 准确命令

```bash
# 必要测试（41 个用例，含 40 组固定种子的随机差分与独立解析参考）
python -m unittest discover -s tests -v

# 固定输入演示（真实计算，约 0.03 s；远小于 8 s 预算）
python demo.py
```

演示打印：一个闭合解析球的顶点/面数、**面积**（对照 4πR²）、散度定理
体积（对照 4/3πR³）、**非流形边计数**、开口边数、Euler 示性数；斜平面
截盒面积的独立解析对照；一个零面积丢弃实例的可定位记录；以及两个实际
触发的拒绝（NaN 标量、bool 维度）。无 `sleep`、无预录结果。

## 公开接口

```python
from mtiso import ScalarGrid, extract_isosurface
from mtiso import (
    MAX_GRID_N, MIN_GRID_N,        # 16, 2
    CUBE_CORNERS, CUBE_TETRAHEDRA, # 角点表与 6 四面体分解表（公开契约）
    TETRA_EDGES, MARCHING_TET_TABLE,
)

grid = ScalarGrid(nx, ny, nz, values, origin=(0,0,0), spacing=(1,1,1))
mesh = extract_isosurface(grid, iso)
```

- `ScalarGrid`（冻结 dataclass）
  - `nx,ny,nz`：每维节点数，整数且 `2 <= n <= 16`（**题面接口边界**，
    拒绝 `bool`）。
  - `values`：长度恰 `nx*ny*nz`，行主序
    `id = ix + nx*(iy + ny*iz)`；元素为有限实数，拒绝 `bool`/`NaN`/
    `±Infinity`，错误消息带一维下标与 `(ix,iy,iz)`。
  - `origin`：节点 `(0,0,0)` 世界坐标；`spacing`：每维步长，三分量须
    为有限**严格正**实数。
- `extract_isosurface(grid, iso) -> MeshResult`（纯函数，不改输入）
  - `vertices`：交点世界坐标元组，下标即顶点 ID；
  - `faces`：`Triangle(vertex_ids=(i,j,k))`，绕序使几何法向指向
    **标量增大方向**；
  - `discarded_faces`：几何零面积丢弃记录 `DiscardedFace(voxel,
    tetrahedron, triangle, edge_keys, reason="zero_area")`；
  - `edge_vertices`：`(min_node_id, max_node_id) -> 顶点 ID`，这是
    “共享边交点”的直接凭据；
  - `boundary_edge_keys`（恰被 1 个面引用）、
    `nonmanifold_edge_keys`（被 ≥3 个面引用）；
  - `stats: MeshStats`：体素/四面体计数、含面四面体数、生成/保留/丢弃
    面数、`level_tetrahedra_skipped`、顶点/面数、开口边数、非流形边数、
    域边界上的等值面顶点数、`surface_area`。

## 输入上限

| 参数 | 范围 |
|---|---|
| 每维节点数 `nx,ny,nz` | 整数 `[2, 16]`（最多 16³ = 4096 节点） |
| 体素数 | 最多 15³ = 3375，四面体 20250 |
| 标量 / iso | 任意有限 IEEE-754 双精度实数 |

## 算法与设计取舍

1. **统一 6 四面体分解（表公开）**：每立方体都沿主对角线
   `角点0 — 角点6` 剖分，6 个四面体为
   `(0,1,2,6) (0,2,3,6) (0,3,7,6) (0,7,4,6) (0,4,5,6) (0,5,1,6)`，
   每个对应 6 条“不接触 0/6”的立方体棱之一；体积各 1/6、绕序统一、
   铺满立方体。分解不随立方体位置翻转，因此**相邻立方体在共享面上的
   剖分对角线逐位一致**，配合全局边键保证跨体素 watertight。
2. **四面体面片表（16 项）**：按 4 顶点 above/below 掩码，1/3 分类出
   1 个三角形，2/2 分类的四边形截交剖成 2 个三角形（共享一条截面
   对角线），0/4 无面。表只给连接结构；**绕序统一由几何定向步骤校正**
   （面叉积与“above 质心 − below 质心”点积取正），不依赖手工绕序表。
3. **共享边交点**：交点缓存键为排序后的全局节点 ID 对
   `(min,max)`；网格边含轴对齐棱、共享面对角线与统一体对角线。节点
   世界坐标预算一次并全程复用，同一节点经任意边引用坐标逐位一致。
4. **iso 恰落节点的符号扰动**：值严格 `>iso` 为 above、`<iso` 为
   below；值恰 `==iso` 时按**全局节点 ID 奇偶**决定拓扑归属（偶 ID
   above、奇 ID below），仅影响连边/掩码，**插值几何位置不变**——
   交点仍是真实线性插值结果；端点恰等 iso 时参数 `t` 恰为 0 或 1，
   顶点精确位于该节点。两端恰等且被扰动判为跨立的边，交点取被判为
   above 的端点（扰动极限）。
5. **全维等值集**：某四面体 4 个真实值全部恰等于 iso 时，等值集是整个
   四面体（三维）而非二维曲面，跳过并计入 `level_tetrahedra_skipped`，
   不伪造面片（常量场 `iso==const` 即此情形）。
6. **零面积丢弃**：三角形两边叉积分量**精确全为 0**（三顶点重合或
   共线）才丢弃并记录，判定不用任何容差。保留面面积按
   `½|(p1−p0)×(p2−p0)|` 累加。
7. **错误语义**：构造期完整校验，非法输入抛带定位信息的
   `TypeError`/`ValueError`，不静默纠正、不钳制；提取是纯函数，失败
   即无调用、无部分变更，不存在需要回滚的有状态批次。
8. **无“搜索预算/无解”概念**：本算法是对全部体素的确定性一次性枚举，
   不是带预算的搜索，故不存在“预算耗尽 vs 证明无解”的分支——所有掩码
   情形都有显式面片表条目，空场就是确定的空结果（0 顶点 0 面）。

## 浮点误差口径（明确，不以宽容差掩盖边界错误）

1. **拓扑与组合判定是精确的**：above/below、掩码选面、边共享、面/边
   计数、Euler、零面积判定（叉积 `== (0,0,0)`）全部基于精确值比较，
   不使用 epsilon；测试中的拓扑断言（闭合、流形、Euler=2、边键集合
   相等、坐标逐位相等）都是**精确等式**。
2. **节点坐标精确复用**：每个节点世界坐标只计算一次；沿网格边的线性
   插值为一次除法 `t=(iso−va)/(vb−va)` 加三次乘加。对**线性标量场**，
   实数意义上插值点严格在等值平面上；浮点残差仅来自少量舍入，测试界
   为 `64·eps·(|iso|+|常数项|)`，`eps≈2.22e-16`（演示平面实际残差为
   0，整盒截面面积与独立 shoelace 参考相对差约 5e-16）。
3. **离散化误差是 O(h²) 的真实几何误差，不是浮点误差**：对光滑曲面，
   分段线性面片只在网格节点上精确，边内截断二次及以上场。径向偏差上
   界（二次场）为 `h²/(2R)`；球面积/体积随 h 减半按约二阶收敛
   （h=0.5 时面积偏差约 1.5%、体积约 2.6%，h=1 时约 6.2%/10.6%）。
   README 与测试均显式给出该量级，不用宽限差冒充精确。
4. **面积求和**：三角形面积简单顺序求和，16³ 规模下求和重排引入的
   相对差在 1e-12 量级（平面解析对照实测 ~1e-15）。

## 已知限制（本题数学子集，不宣称行业标准兼容）

- 仅支持规则轴对齐网格上的三线性节点数据、沿四面体棱的**线性**插值；
  不是通用 VTK/ITK 风格的多单元、自适应或高阶等值面实现。
- 共享只按**网格边键**，不做坐标合并：iso 恰好穿过网格节点时，该节点
  可由数条边键各持一个坐标相同的顶点。这是契约规定的键共享语义；由此
  可能产生零面积面（已丢弃记录）或开口/非流形组合统计（如实报告），
  不做后处理焊接。
- 非流形/开口边统计基于输出顶点 ID 的三角形边，不按几何坐标去重。
- 单线程 CPU、面向 ≤16³ 的题库规模；未为超大体数据做分块/并行。
- 不输出文件格式（PLY/STL 等）、不做网格简化、平滑或法线重计算。
